# Physics Olympiad Guide

An AI-Human hybrid-powered database to improve your physics to the Olympics level.

https://pho-guide.org | https://github.com/sherlockdong/newpho/tree/main

## Overview

- This project is entirely built and run by current high school students. It integrates Artificial Intelligence (ChatGPT 5.4 and 5.4 mini) to provide a more personalized experience for students. 

- The project addresses the current scarcity of educational equity in the society, and aim to help every high school student. 

- The project is unique for its combination between traditional database and modern AI agents.

## Intended Audience

- The project is designed for every high school students that need help with physics. Register an account, and you can start exploring. 
- To get started, you would not really need to know anything about physics. Studying resources are provided for each high school topics on the website. 
- CUrrently, the website supports all topics covered in high school physics in the U.S, F=ma, Physics Bowl, and USAPhO. 

## Key Features

### Quizes

- Log in to your account, and go to a topic, and you can click on "Initialize Telementry" and get started with AI - Generated quizes. 

### Insights

- In the Insight section, there are articles published regularly for students to learn about physics and tips to learn about physics competitions.

### Roadmap

- The roadmap section offers a clear overview of how each node is interconnected, and the pre-reqs to learn before reaching certain more advanced topics. 

### Logs

- The Log section shows you your past practices, as well as how well you did. It can also be shown at your User page. 

## How It Works

1. Log in / Register with an email address / google account. 
2. Choose what level of physics you want to learn about. 
3. When you feel ready, start taking a quiz. 
4. Read the feedbacks that AI generates base on your performances. 
5. Learn about the results, and take the quiz again later.

- Database: Supabase
- Authentication: Email / Google
- AI services/models: ChatGPT 5.4 and 5.4 mini,
- Hosting/deployment: Vercel
- Development Workflow Tooling: Lint, Husky.
